<Warning>
  `liquidityRewards` has been removed from `@outcome.xyz/hip4`. This page stays at its existing URL so old links (including the changelog entries below) keep resolving to something useful - it no longer describes a working SDK feature.
</Warning>

## What happened

`liquidityRewards` queried Monarch's World Cup 2026 campaign API (season `s1`, June 11 - July 19, 2026) for team/match eligibility and per-wallet reward scores. That campaign has permanently ended: Monarch's campaign endpoints (`/marina/campaigns/world-cup-2026/*`) now return `410 Gone` on every route, for any date -

```json
{ "error": "World Cup 2026 public API retired", "code": "WORLD_CUP_2026_API_RETIRED" }
```

Season `s1` was the only season ever registered, and its upstream API is gone for good, so the entire module was removed from the SDK's public exports: `liquidityRewards`, `.season()`, `checkEligibility()`, `checkRewards()`, `LIQUIDITY_REWARDS_CONFIG`, `LiquidityRewardsError`, and every `LiquidityRewards*` type.

## What replaced it

Outcome Markets rewards - an ongoing programme covering all prediction markets, not a single retired campaign - are queryable through the new **`outcomeRewards`** module. See [Outcome Rewards](/sdk/reference/outcome-rewards).

It answers a different question than `liquidityRewards` did: `liquidityRewards` told you which books were *eligible today*; `outcomeRewards` tells you what has *already been paid out* - programme totals, one wallet's earnings, finalized reward periods, and a leaderboard. There's no eligibility-checking equivalent in the new module.
